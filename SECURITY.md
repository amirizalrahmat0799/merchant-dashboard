# Security

Merchant Dashboard is a portfolio project that simulates payment systems. It is not affiliated with any real payment scheme, bank or card network, and it is not meant to handle real money or real customer data.

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- through GitHub: **Security > Report a vulnerability** on this repository, or
- by email to amirizalrahmat@gmail.com.

Include the steps to reproduce and the version or commit you tested. I will reply within a week.

## Supported versions

Only the latest version on `main` receives fixes.

## Known limitations

The demo keeps the merchant's API key in the browser, as the README notes. A production dashboard would use a server-side session instead.
